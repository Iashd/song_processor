# song_processor
This is a WIP python script that allows you to:

- Search for a song on YouTube

- Download the song

- Extract the vocals

- Save the vocals

It allows you to automatically get vocals from any given song in a matter of seconds, and works... somewhat flawlessly.

I created this using Claude 3.7 and it suprisingly worked, so I am uploading it here for anybody who would like to try it out and maybe I inpsire others to create something better.

---------------------------

Tutorial:

Run the .exe in the \Dist folder

or

Run the .pyw file.

Type the name of a song, confirm the song, then wait.

Check the vocals folder
